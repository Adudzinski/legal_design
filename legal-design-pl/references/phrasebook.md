## 1. Kancelaryzmy → prosta polszczyzna

| Kancelaryzm | Prosta polszczyzna |
|---|---|
| niniejszy / niniejszym | ten / ta / to — albo usuń w całości |
| przedmiotowy / rzeczony | ten / ta / to |
| w związku z powyższym / wobec powyższego | dlatego |
| z uwagi na fakt, iż / z uwagi na okoliczność | ponieważ |
| w przypadku gdy / w razie gdyby | jeśli / gdy |
| z zastrzeżeniem [X] | z wyjątkiem [X] / o ile [X] nie stanowi inaczej |
| celem [zrobienia czegoś] | aby [coś zrobić] |
| w terminie 14 dni | w ciągu 14 dni / masz na to 14 dni |
| w miesiącu maju / w dniu dzisiejszym | w maju / dzisiaj |
| środki pieniężne | pieniądze |
| wytyczne | wskazówki |
| zastrzeżenia | uwagi |
| zweryfikować | sprawdzić |
| udostępnić do wglądu | pokazać / dać do przeczytania |
| uprzednio | wcześniej |
| stosownie do / zgodnie z treścią | zgodnie z |
| w szczególności | `np.` / `na przykład` / `między innymi` — **tylko jeśli** oryginał naprawdę oznacza katalog otwarty; w innym razie zostaw, ten zwrot niesie skutek prawny. Prawnik w przeglądzie wybrał `np.` (`np. komputer, telefon czy dostęp do internetu`) |
| jest obowiązany / zobowiązany jest [zrobić] | tryb rozkazujący (`Przestrzegaj…`) albo `masz obowiązek [zrobić]` — nigdy `prosimy` |
| nie później niż [termin] | najpóźniej [termin] — ten sam zakres, wolno zamienić |
| w terminie do [dnia] | do [dnia] |
| bez względu na | niezależnie od tego |
| zastosowanie mają przepisy | obowiązują przepisy |
| odrębny | osobny |
| nieodpłatnie | bezpłatnie |
| w postaci papierowej lub elektronicznej | na papierze lub elektronicznie |
| bądź / lub też | lub |
| oraz / a także | i |
| jak również | i |

W tekstach konsumenckich całkowicie unikaj łaciny: *ipso facto*, *sui generis*, *a contrario*, *de facto*.

Rozwijaj skróty nieprawnicze: `m.in.` → `między innymi`, `tj.` → `to jest`, `ww.` → nazwij rzecz jeszcze raz, `itp.` → przeformułuj.

## 2. Rzeczowniki zombie → czasowniki

Rzeczowniki zakończone na `-anie`, `-enie`, `-cie`, `-ość` zwykle ukrywają czasownik. Przywróć go.

| Rzeczownik | Czasownik |
|---|---|
| dokonać zapłaty | zapłacić |
| dokonać rejestracji | zarejestrować się |
| dokonać zgłoszenia | zgłosić |
| dokonać wyboru | wybrać |
| w celu dokonania weryfikacji | aby sprawdzić |
| następuje rozwiązanie umowy | umowa się kończy |
| ulec rozwiązaniu | zakończyć się |
| dokonać akceptacji | zaakceptować |
| przystąpić do realizacji | zacząć / wykonać |
| wyrazić zgodę na przetwarzanie | zgodzić się na przetwarzanie |
| dokonanie płatności następuje | płacisz |
| złożenie reklamacji | reklamacja / gdy reklamujesz |

## 3. Nazwy stron

| Nazwa prawna | Prosto | Warunek |
|---|---|---|
| Usługodawca / Administrator / Spółka | my | Tylko jeśli `my` jest zdefiniowane w `§ definicje` |
| Użytkownik / Klient / Abonent | Ty | Tylko jeśli `Ty` to wybrana forma zwracania się |
| Strony | my i Ty | Sprawdź, czy brzmi naturalnie w kontekście |

Jeśli `my` i `Ty` nie są zdefiniowane, nie wprowadzaj ich po cichu. Powiedz użytkownikowi, że dodanie dwóch definicji pozwoliłoby używać ich w całym dokumencie, i zostaw decyzję jemu — dodanie definicji to zmiana treści, więc należy do niego, nie do umiejętności.

## 4. Przykłady na pełnych zdaniach

**Strona bierna → czynna**

- PRZED: `Dane osobowe Użytkownika są przetwarzane przez Administratora w celu realizacji Umowy.`
- PO: `Przetwarzamy Twoje dane osobowe, aby wykonać Umowę.`
- Co zmieniono: strona bierna → czynna; rzeczownik zombie `realizacji` → `wykonać`; nazwy stron → `my`/`Ty`. `Umowa` jest terminem zdefiniowanym, więc zachowuje wielką literę.

**Forma bezosobowa → osobowa**

- PRZED: `Należy niezwłocznie poinformować Usługodawcę o wszelkich nieprawidłowościach.`
- PO: `Poinformuj nas od razu, jeśli coś działa nieprawidłowo.`
- Uwaga: `niezwłocznie` to termin o ugruntowanym znaczeniu prawnym. `od razu` jest dopuszczalne w tekście konsumenckim, ale oznacz flagą, jeśli z przepisu wynika skutek terminowy — część autorów opiera się właśnie na utrwalonej wykładni słowa `niezwłocznie`.

**Warunki zagnieżdżone → lista** (wzorzec kluczowy)

- PRZED: `Użytkownik może odstąpić od Umowy w terminie 14 dni od dnia jej zawarcia, chyba że Usługa została w całości wykonana za wyraźną zgodą Użytkownika przed upływem tego terminu, o czym Użytkownik został uprzednio poinformowany.`
- PO:
  ```
  Możesz odstąpić od Umowy w ciągu 14 dni od jej zawarcia.

  Nie możesz tego zrobić, jeśli spełnione są wszystkie trzy warunki:
  - wykonaliśmy Usługę w całości,
  - zgodziłeś się na to wyraźnie przed upływem 14 dni,
  - uprzedziliśmy Cię wcześniej, że stracisz prawo do odstąpienia.
  ```
- Uwaga do audytu: w oryginale warunki są **łączne** — wyjątek działa dopiero, gdy zachodzą wszystkie trzy. Lista musi to powiedzieć wprost przez `wszystkie trzy warunki`. Same trzy punkty bez tego wprowadzenia czytelnik odbierze jako warunki **alternatywne**, co zmieniłoby skutek prawny. To dokładnie ten błąd, który ma wychwytywać audyt.

**Usunięty imiesłów**

- PRZED: `Korzystając z Aplikacji, Użytkownik akceptuje postanowienia Regulaminu.`
- PO: `Gdy korzystasz z Aplikacji, akceptujesz Regulamin.`

**Rozbite zdanie**

- PRZED: `W przypadku gdy reklamacja nie zostanie rozpatrzona w terminie 14 dni od dnia jej otrzymania, uważa się ją za uwzględnioną, z zastrzeżeniem ust. 5.`
- PO: `Mamy 14 dni na rozpatrzenie Twojej reklamacji, licząc od dnia, w którym ją otrzymamy. Jeśli w tym czasie jej nie rozpatrzymy, uznajemy reklamację za przyjętą. Wyjątki opisaliśmy w ust. 5.`
- Co zmieniono: podział na trzy zdania; strona bierna → czynna; `w przypadku gdy` → `jeśli`; `z zastrzeżeniem` → wyraźne odesłanie. Odesłanie do `ust. 5` zostaje i nadal dotyczy tej samej zasady.

## 5. Pułapki właściwe dla polszczyzny

**Tych słów nie upraszczaj** — niosą skutek prawny, a ich zamiana zmienia zakres:
`w szczególności` (sygnalizuje katalog otwarty), `nie później niż`, `co najmniej`, `wyłącznie`, `jedynie`, `odpowiednio`, `niezwłocznie`, `rażący`, `istotny`. Upraszczaj zdanie wokół nich.

**Nazwa strony po przejściu na `my`.** Gdy dokument mówi `my`, nie wprowadzaj trzeciej nazwy (`firma`, `spółka`, `zakład`) ani zamiennie małej i wielkiej litery (`pracodawca` / `Pracodawca`). Zostają dwie formy: `my` w tekście i zdefiniowany `Pracodawca` tam, gdzie potrzebna jest nazwa (§ 1, formuły o trybie ustalenia, sankcje).

**Spójność jest ważniejsza od elegancji.** Jeśli `Konto` jest terminem zdefiniowanym, to każde wystąpienie brzmi `Konto` — nigdy `profil`, nigdy `konto użytkownika`, nigdy zaimek tam, gdzie mogłaby powstać wieloznaczność. Powtórzenia, które w eseju byłyby wadą stylu, w dokumencie prawnym są poprawne.

**Rodzaj gramatyczny a forma `Ty`.** Formy czasu przeszłego w 2. osobie są rodzajowe (`zgodziłeś` / `zgodziłaś`). Dla szerokiego odbiorcy wybieraj konstrukcje, które to omijają: czas teraźniejszy, tryb rozkazujący, `Twoja zgoda`, `masz prawo`, `jeśli chcesz`. Gdy alternatywa jest nieunikniona, formy podwójne są dopuszczalne — prawnik w przeglądzie regulaminu pracy sam użył `przychodził(a)`, `powinieneś/powinnaś` i `koleżankę lub kolegę`. Wybierz jedną konwencję (nawias albo ukośnik) na cały dokument i powiedz użytkownikowi którą.

**`Państwo` łączy się z czasownikiem w 3. osobie.** `Pisali Państwo`, nigdy `Pisaliście Państwo`. To częsty błąd w dokumentach, które w połowie zmieniają rejestr.

**Wielka litera sygnalizuje definicję.** Jeśli termin ma wielką literę w środku zdania, prawdopodobnie jest zdefiniowany. Sprawdź `§ definicje`, zanim go ruszysz. Jeśli ma wielką literę, ale **nie** jest zdefiniowany — oznacz flagą. To wada oryginału, którą warto zgłosić.
